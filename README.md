# رياضيات التعليم المتوسط

رابط واحد ثابت للتلاميذ: `https://soufiyousfi.github.io/math/`

## البنية (structure)

```
المستوى (level)      الفصل (term)       القسم (section)
1m  السنة الأولى     t1  الفصل الأول     dars      الدروس التفاعلية (شرح، محاكاة، ألعاب، شهادة)
                                          series    سلاسل التمارين
2m  السنة الثانية    t2  الفصل الثاني    fard      الفروض
3m  السنة الثالثة    t3  الفصل الثالث    wadjib    الواجبات المنزلية
4m  السنة الرابعة                         ikhtibar  الاختبارات
                                          chahada   سلاسل الشهادة (للرابعة فقط)
                                          tahaddi   التحديات (صفحة تحدٍّ + صورة للنشر في img/)
```

مثال: واجب السنة الرابعة، الفصل الأول ← `4m/t1/wadjib/`

## إضافة ملف جديد من الهاتف

1. افتح المستودع (repository) ← **Add file** ← **Create new file**
2. اكتب المسار (path) كاملًا في خانة الاسم، مثل: `4m/t1/wadjib/wadjib-03.html`
3. الصق محتوى الصفحة ← **Commit changes**

بعد دقيقة تقريبًا يظهر الملف في الصفحة الرئيسية (index page) تلقائيًا، مع شارة «جديد» لمدة 7 أيام.

- لرفع ملف PDF أو صورة: ادخل المجلد (folder) المناسب ← **Add file** ← **Upload files**.
- العنوان الظاهر للتلاميذ يُؤخذ من وسم `<title>` في ملف HTML، وإلا من اسم الملف (`wadjib-03` ← «wadjib 03»).
- سلسلة من عدة ملفات (صور، صفحة حل…): ضعها في مجلد خاص يحتوي `index.html`، مثل `3m/t2/series/series-04/index.html`.

## رابط مباشر لمستوى وفصل

`https://soufiyousfi.github.io/math/#4m-t1` ← يفتح مباشرة على السنة الرابعة، الفصل الأول.

## إعداد لمرة واحدة

Settings ← Pages ← Source: **GitHub Actions**

## صورة المعاينة عند مشاركة الرابط (فيسبوك، واتساب…)

كل صفحة تظهر تلقائيًا بصورة تناسب نوعها ومستواها: `og/<المستوى>-<القسم>.jpg` (مثل `og/3m-series.jpg`).
صفحة لها صورتها الخاصة (وسم `og:image` داخلها، مثل التحديات) تحتفظ بصورتها.
